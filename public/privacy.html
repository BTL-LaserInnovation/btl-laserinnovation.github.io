사이트 개인정보 안내

최종 수정일: 2026년 11월 10일

이 안내는 여러 비상업용 소프트웨어를 소개하는 BlueOcean 공통 홈페이지에 적용됩니다. 개별 소프트웨어에서 처리하는 계정·설정·일정 정보는 해당 서비스의 개인정보처리방침을 확인하세요.

선택한 화면 언어(한국어 또는 영어)는 브라우저의 로컬 저장소에 저장해 다음 방문에도 유지합니다. 이 설정은 서버로 전송하지 않으며, 저장소 사용이 제한되면 페이지 주소의 언어 선택 값으로 페이지 간 선택을 유지합니다.

1. 홈페이지에서 처리하는 정보

홈페이지 자체에는 회원가입, 광고·방문 분석 스크립트, 개인정보 수집 폼을 두지 않습니다. 화면을 표시하기 위한 이미지와 스타일은 같은 사이트에서 제공합니다. 홈페이지를 열었다는 이유만으로 Codex나 Google 계정이 연결되거나 개인 일정이 조회되지 않습니다.

2. 호스팅과 외부 링크

이 홈페이지는 GitHub Pages로 게시하도록 구성되어 있습니다. GitHub는 사이트 제공과 보안을 위해 접속 IP 등 방문 정보를 처리할 수 있습니다. GitHub 개인정보처리방침을 확인하세요. 다운로드·소스·문의 등 외부 링크를 누르면 해당 제공자의 사이트로 이동하며 그 서비스의 정책이 적용됩니다.

3. 서비스별 개인정보처리방침

  • Codex Pulse 개인정보처리방침: Codex 계정 표시, Google 캘린더 연결, 로컬 저장과 삭제 방법

4. 문의

현재 제공 중인 Codex Pulse에 대한 문의는 프로젝트 문의 게시판에서 접수합니다. 공개 게시판이므로 비밀번호, 로그인 토큰, 개인 일정 등 민감한 정보를 게시하지 마세요.

5. 안내 변경

홈페이지의 정보 처리 방식이나 제공 서비스가 바뀌면 이 페이지와 최종 수정일을 갱신합니다.
