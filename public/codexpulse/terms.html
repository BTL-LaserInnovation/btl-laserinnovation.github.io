CODEX PULSE / TERMS

이용약관

시행일·최종 수정일: 2026년 11월 10일

이 약관은 BTL-LaserInnovation/CodexPulse 프로젝트가 제공하는 Windows 앱 Codex Pulse와 이 소개 사이트의 이용 조건을 설명합니다.

1. 제공 기능

Codex Pulse는 Codex 계정의 사용량·리셋권, 공개 리셋 자료와 선택적으로 연결한 Google 캘린더를 표시하는 데스크톱 위젯입니다. Google 캘린더 연결 시 사용자가 허용한 범위에서 일정을 조회·추가·수정·삭제할 수 있습니다. OpenAI나 Google의 공식 제품이 아니며 해당 계정이나 구독 자체를 제공하지 않습니다.

2. 계정과 사용 권한

사용자는 본인에게 접근 권한이 있는 계정과 캘린더만 연결하고, 각 외부 서비스의 이용 조건을 따라야 합니다. Google 로그인은 Google의 브라우저 화면에서 진행하며 연결은 선택 사항입니다. Google의 공개 검증이 아직 완료되지 않아 연결 시 미확인 앱 안내나 접근 제한이 나타날 수 있습니다. 사용 계정과 조직의 Google 정책에 따라서도 연결이 제한될 수 있습니다.

3. 일정 변경과 리셋권 사용

앱에서 저장한 일정 변경은 실제 Google 캘린더에 반영되며 다른 기기에도 동기화될 수 있습니다. 삭제 확인창의 제목과 날짜를 확인하세요. 반복 일정의 해당 회차 삭제와 전체 반복 삭제는 범위가 다릅니다. Codex 리셋권 사용도 연결된 계정에 실제 적용되는 요청이므로 확인창의 계정과 선택 항목을 확인한 뒤 진행해야 합니다.

4. 정보의 정확성과 외부 서비스

사용량·리셋 예정·공개 기록은 외부 제공자의 자료와 네트워크 상태에 따라 갱신이 지연되거나 달라질 수 있습니다. 공개 리셋 기록은 개인 계정에 적용됐다는 보장이 아닙니다. Google, OpenAI, GitHub 또는 자료 제공자의 정책·권한·서비스 상태에 따라 일부 기능이 제한되거나 변경될 수 있습니다.

5. 비용과 업데이트

프로젝트가 제공하는 Codex Pulse 설치 파일은 현재 무료로 배포합니다. OpenAI 구독, 네트워크 및 외부 서비스 이용 비용은 별개입니다. 업데이트는 GitHub Releases에서 제공하며 설치형 앱의 Update 버튼이나 최신 설치 파일로 진행할 수 있습니다.

6. 데이터 관리

계정·일정·로컬 설정의 접근, 저장, 연결 해제와 삭제 방법은 개인정보처리방침에 따릅니다. 앱 제거와 Google 계정의 접근 권한 철회는 서로 다른 작업입니다.

7. 제공 상태와 지원

프로젝트는 현재 제공 가능한 상태로 앱을 제공하며, 외부 서비스의 지속적인 가용성이나 표시 정보의 완전성을 보장하지 않습니다. 중요한 일정과 정보는 원본 서비스에서도 확인하세요. 이 안내는 관련 법령에서 인정하는 사용자의 권리나 제공자의 책임을 배제하려는 것이 아닙니다.

문의와 오류 신고는 GitHub 프로젝트 문의에서 접수합니다. 공개 게시판에는 로그인 토큰이나 개인 일정 등 민감한 정보를 게시하지 마세요. 소스코드와 포함된 구성 요소의 이용에는 저장소 및 해당 구성 요소의 별도 이용 조건도 확인해야 합니다.

8. 약관 변경

기능이나 제공 조건에 변경이 있으면 이 페이지의 내용과 수정일을 갱신합니다. 중요한 변경은 프로젝트의 공개 안내와 릴리즈 기록을 통해 알립니다.
